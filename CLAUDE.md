# CLAUDE.md

## Git

Условие для любых правок:

1. Создавай отдельную ветку от master.
2. Не коммить прямо в master.
3. Перед git push и созданием PR всегда спрашивай моё подтверждение.
4. После создания PR дай мне ссылку.

- Используй /commit после каждого завершённого блока работы (в рабочей ветке, не в master).
- После важных этапов делай /commit-push-pr — только после моего подтверждения (см. п. 3).
