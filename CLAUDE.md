# CLAUDE.md

## Git

- Работай в ветке master.
- Не создавай новые ветки.
- Не создавай Pull Request.
- Не делай git push без моей явной команды.
- После завершённого изменения делай git add и git commit с коротким понятным сообщением.
- Не коммить .env, токены, ключи, пароли и личные данные.

## Работа

- Перед изменениями сначала показывай короткий план и список файлов.
- После изменений показывай список изменённых файлов и краткое описание.
- Отвечай кратко, без длинных объяснений.
- Не читай файлы целиком, если достаточно нужного фрагмента.
- Не используй MCP и внешние сервисы, если задача этого не требует.
